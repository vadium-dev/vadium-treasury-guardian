THE PROBLEM

Agents transact autonomously. When something goes wrong, there is no recourse.

Virtuals Protocol — co-author of ERC-8183, the escrow standard this ecosystem is built on — has publicly discussed managing agent transaction volume without escrow.

$3M+ in agent transactions, no escrow

The standard itself names the gap. ERC-8183’s own spec text, plainly:

“A malicious evaluator can complete or reject arbitrarily.” “No dispute resolution or arbitration; reject/expire is final.”

Never addressed anywhere in the post: who verifies, when the parties disagree. No dispute resolution. No arbitration. No reputation mechanism. That is the entire gap Vadium fills.

02

WHAT VADIUM IS

Sellers post real collateral. Two payout paths, never one mechanism doing both.

Objective path

Schema failure, failed attestation, duplicate output. Fully code-verifiable. Slashes automatically — no human, no committee.

Discretionary path

A genuine judgment call. Routes to an independent committee vote. Never a single call from us, or from anyone.

Hedge coverage

A buyer can pre-purchase coverage on a seller. Priced like real insurance — premium never refunded, payout bounded by what was insured.

Everything keys to the seller’s ERC-8004 identity — never to whichever wallet a payment happens to land in.

BUSINESS MODEL

Revenue scales with real risk, not a flat subscription.

Reputation lookup

Free tier live today, priced by agent-usage via x402 in a paid tier. Discovery through the same machine-first channels agents already use — the ERC-8004 registry, Circle’s Agent Marketplace, x402 Bazaar. No separate sales motion.

Hedge premium

Priced like real insurance: expected loss plus a margin. A buyer’s own risk logic chooses to hire it exactly when a transaction warrants it — self-selecting demand, not a pitch.

Margin improves with scale: marginal cost per verified transaction stays small while the fixed compliance/engineering base amortizes.

THE ONE HONEST GAP

Real legal review of the collateral mechanism — not done yet, and not skipped.

Nexus Mutual, the category leader, deliberately did not go pure-smart-contract — they wrapped a real legal structure around their mechanism specifically because insurance is already a highly regulated space, and no amount of clever code changes how a regulator characterizes the underlying activity. We built the same discipline in from the start: the objective/discretionary split, and holding no custody on either side, are structural choices made with exactly this review in mind.

Everything upstream of this is already proven, live, on testnet. This is the only remaining step before real value moves — and it is fundable, not just necessary.
